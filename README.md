# Everyday Eats — Final deliverables

Everyday Eats is a mobile food and nutrition app with two jobs: tell me what's in this dish or product, and help me find something good to cook. These are the three final deliverables. Each folder stands on its own and can be uploaded or submitted separately.

| Folder | Deliverable | Start with |
| --- | --- | --- |
| [01-branding-stylescape](01-branding-stylescape) | Branding / stylescape | `everyday-eats-stylescape.pdf` |
| [02-design-system](02-design-system) | Design system: foundations, typography, colour, spacing, components and tokens | `README.md`, then `everyday-eats-design-system.pdf` |
| [03-key-screens-and-flows](03-key-screens-and-flows) | The 15 final high-fidelity screens and the five UX flows | `README.md`, then `everyday-eats-key-screens-and-flows.pdf` |
